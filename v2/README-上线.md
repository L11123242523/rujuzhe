# 入局者 v2 · 上线清单

这个目录是**纯静态**发布包（无 Node 依赖、无构建步骤、无外部 CDN）。
把它整个上传到静态空间的某个子路径即可。

## 一、先传成"子路径预览"（推荐）

1. 把本目录里的**所有文件**上传到 `https://<你的域名>/v2/`
2. 访问 `https://<你的域名>/v2/` —— 能打开界面、能点"新开一局"就成了
3. **老站不要动**：`game.html` 与 `assets/` 保持原样，玩家仍从首页进老站

> 为什么不直接换首页：v2 现在只有"单机 vs AI"，**没有联机、没有组卡界面、没有乐谱/遗物演出、没有移动端适配**。
> 直接替换首页 = 功能倒退；先并排跑，等缺口补完再换。

## 二、文件清单（共 185 个）

| 路径 | 作用 |
|---|---|
| `index.html` | 界面入口（**访问 `/v2/` 时服务器要能返回它**） |
| `ui.js` / `style.css` | 界面逻辑与样式 |
| `cards.json` | 全部 167 张卡的内容（构建期由 content/ 合成） |
| `assets/cards/*.webp` | 卡图（宽 300px，作者新卡面优先） |
| `assets/index.json` | 卡图索引（id → 文件 / 来源 / sha256） |
| `packages/engine/**` | 引擎（无 DOM、无 setTimeout、无 Math.random） |
| `packages/ai/**` | AI |
| `dist-manifest.json` | 文件清单 + sha256（用于校验上传是否完整） |

## 三、服务器要求

- **必须是 HTTP(S)**：ES 模块在 `file://` 下会被浏览器拦掉
- **MIME**：`.js`、`.mjs` → `text/javascript`；`.json` → `application/json`；`.webp` → `image/webp`
- **目录索引**：`/v2/` 要能返回 `/v2/index.html`（Nginx 默认可以；若不行就让人访问 `/v2/index.html`）
- **缓存**：卡图可以长缓存（`Cache-Control: max-age=604800`），
  `index.html`/`ui.js`/`cards.json` 建议 `no-cache`（或每次发布改文件名），否则玩家会拿到旧版
- 不需要 Node、不需要数据库、不需要 WebSocket（**联机还没做**）

## 四、上线后怎么验证（30 秒）

1. 打开 `/v2/` → 标题是「入局者 · v2（全新引擎）」
2. 点「新开一局」→ 双方各 4 张手牌、地图 42 格、日志出现"第 1 回合"
3. 点一张手牌 → 有牌进墓地/进效果处理区，日志有【出牌】【伤害】之类
4. 点「结束回合」→ AI 会自己走一回合
5. 打开浏览器控制台：**不应有红色报错**（有的话把那行发我）

## 五、回滚

- 这个包**完全独立**，不碰老站任何文件 ⇒ 回滚 = 把 `/v2/` 目录删掉
- 如果你之后把首页换成 v2：提前把老 `index.html` 备份改名（例如 `index.old.html`），回滚时改回来即可

## 六、安全/隐私

- 纯静态、无后端 ⇒ 没有服务器侧数据；玩家的对局只存在浏览器内存里（**没有存档**）
- 不含统计/埋点/外链（`cards.json` 与卡图都在本目录内）

## 七、已知缺口（发布前你应该知道）

- 只有单机 vs AI；**没有联机**
- 没有组卡界面（卡组是按 §2.1 自动组的）
- 界面是最小可用版：无动画、决策是按钮、无移动端适配
- 引擎侧仍有 4 项"已登记未接线"的机制（终止移动/决斗/交换格子/废弃的追加投掷布尔），详见《重做记录》P7
